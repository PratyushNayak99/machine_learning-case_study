# Student 3 Research Study: Condition Monitoring of Hydraulic Systems

- **Owner:** Student 3
- **Lead Algorithm:** Random Forest Classifier
- **Dataset:** Condition Monitoring of Hydraulic Systems (UCI ID 447)
- **Target:** `cooler_condition` (Multi-class: 3 = Total Failure, 20 = Reduced Efficiency, 100 = Full Efficiency)
- **Features:** 136 cycle statistical descriptors extracted from 17 multi-rate sensor channels.

## How to Reproduce
From project root:
```bash
python -m students.student_3.run_study
```
